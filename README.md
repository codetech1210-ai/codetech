# Beyond the Stars — Seth Anandram Jaipuria School, Kanpur Cantt

Responsive static school showcase website.

## Local preview

Open `index.html` in a modern browser or use VS Code Live Server.

## Manage gallery through GitHub URLs

1. Upload photos/videos to a public folder in your GitHub repository.
2. Copy each file's **Raw** URL.
3. Add the URL as `src` in `gallery-data.js`.
4. Commit and push changes to the GitHub Pages publishing branch/folder.

All visitors see the same code-configured gallery. The public website has no upload controls or browser-local gallery storage.

See `GALLERY-GUIDE.md` for examples.

## Educator profiles

Edit the `quotes` array at the top of `app.js` to update educator names, titles, quotations and portrait URLs.

## Deployment

Keep `index.html`, CSS/JS files and assets together in the GitHub Pages published root. The project uses relative paths for local project assets.
